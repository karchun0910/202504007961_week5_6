# Week 5-6 Notes

Manhattan distance is admissible because each permitted move changes only one row or column coordinate by one. Therefore, it never estimates more moves than a real four-directional path requires; walls can only keep the true cost equal or make it larger.

The six student-written tests cover complex structure, unsolvable inputs, optimality, dense constraints, a boundary case, and failure handling. I chose this spread to check successful detours and valid choices as well as isolated regions and problems where no solution exists, instead of repeating only normal solvable cases.
